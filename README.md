# Кадр — фото ийрим (окуу сайты)

Автор: Нуртилек, КС-2-24. Кыргыз тилиндеги окуу веб-долбоору.

## Курамы
- `index.html` — барактардын HTML түзүлүшү
- `style.css` — жасалгасы жана мобилдик экранга ылайыкташуу
- `script.js` — меню, сабактарды чыпкалоо, тандоо жана форманы текшерүү
- `images/` — үч мисал сүрөтү (жергиликтүү файлдар)

## Текшерүү
`index.html` файлын браузерден ачыңыз. Менюдагы шилтемелер, «Баштапкы» жана «Практика» баскычтары, «Тандоо» баскычы жана форма иштеши керек. 375 px кеңдикте барак горизонталдуу жылбашы керек.

## Публикация
GitHub'га файлдарды тамыр каталогунда жүктөп, Settings → Pages → Deploy from a branch → main → /(root) → Save. Сайттын ачык дарегин отчетко киргизүү.

## Эскертүү
Бул чыныгы кызмат көрсөтүүчү эмес, окуу макети. Дарек жана форма демонстрациялык, маалымат серверге жөнөтүлбөйт.

Үлгү сүрөттөр scikit-image китепканасынын коомчулукка ачык окуу топтомунан алынган; автордун өз сүрөттөрү катары көрсөтүлбөйт.
